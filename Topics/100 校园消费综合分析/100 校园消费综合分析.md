## 100 校园消费综合分析

给定校园消费 CSV 文件、统计日期 `target_date` 和输出 JSON 文件路径。CSV 首行为 `time,student_id,category,amount`。

只统计日期等于 `target_date` 的合法记录：时间必须符合 `YYYY-MM-DD HH:MM:SS`，学号和类别非空，金额为非负数。跳过其他日期和所有非法记录，并完成综合分析。

返回并写入 JSON 的报告应包含：

- `date`：统计日期
- `valid_records`：合法记录数
- `invalid_records`：字段或格式非法的记录数（其他合法日期不计入）
- `total_amount`：总金额，保留两位小数
- `average_amount`：每笔平均金额，保留两位小数
- `category_amount`：各类别金额，按金额降序、类别升序排列后插入字典
- `student_amount`：各学生金额，按金额降序、学号升序排列后插入字典
- `top3_students`：消费最高的 3 名学生及金额
- `hourly_count`：`00~23` 每小时的消费笔数，必须包含全部 24 个键

#### 示例 1：

> 输入记录：`2026-07-15 08:00:00,001,餐饮,10.5`、`2026-07-15 12:00:00,001,图书,20`、`2026-07-15 12:30:00,002,餐饮,15`
>
> target_date = "2026-07-15"
>
> 结果：合法记录 3，总金额 45.50，学生 001 消费 30.50，12 时有 2 笔消费

#### 示例 2：

> 文件只有表头
>
> 结果：合法记录 0，总金额和平均金额均为 0.00，各排行为空，24 个小时的次数均为 0

#### 提示：

- 使用 `csv` 读取、`time.strptime()` 校验时间、`json.dump()` 写出报告
- 使用 `try...except` 跳过无法转换的金额
- JSON 使用 UTF-8，设置 `ensure_ascii=False` 和适当缩进
- 本题综合考查二级操作题中的输入输出、分支循环、字符串、组合数据、函数、异常、文件、数据格式化与常用库
