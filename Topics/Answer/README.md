# 参考答案说明

本目录对应 `Topics` 中的 `001–100` 题。每道题使用同名文件夹，主程序统一命名为 `题号_main.py`。

运行示例：

```powershell
python ".\Answer\001 温度转换\001_main.py"
```

文件类题目的示例输入也保存在对应文件夹中，运行主程序后，输出文件会生成在同一文件夹。

注意事项：

- `084–088` 使用 Python 自带的 `turtle`，需要桌面图形环境；
- `089–092`、`097`、`099` 使用第三方库 `jieba`，运行前需执行 `pip install jieba`；
- 每份答案都保留了可复用函数，`if __name__ == "__main__"` 下方是运行示例；
- 建议先独立完成题目，再对照答案检查思路、边界条件和输出格式。
