## 075 一元二次方程

给定实数 `a`、`b`、`c`，求方程 `ax² + bx + c = 0` 的实数根。

若 `a = 0`，按一元一次方程处理；无实数根返回空列表；有根则去重并按升序返回，所有根四舍五入到六位小数。若退化成恒等式，返回字符串 `"ALL_REAL"`。

#### 示例 1：

> 输入：a = 1, b = -3, c = 2
>
> 输出：[1.0, 2.0]

#### 示例 2：

> 输入：a = 1, b = 0, c = 1
>
> 输出：[]

#### 提示：

- 判别式为 `b² - 4ac`
- 使用 `math.sqrt()`
- 当 `a = b = c = 0` 时返回 `"ALL_REAL"`
