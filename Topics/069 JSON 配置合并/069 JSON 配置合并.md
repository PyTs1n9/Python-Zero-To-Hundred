## 069 JSON 配置合并

给定两个 JSON 文件路径 `default_path` 和 `user_path`。两个文件的顶层内容都是对象，值可能仍是对象。

用用户配置递归覆盖默认配置：相同键若两侧都是对象则继续合并，否则使用用户值。返回合并后的字典。

#### 示例 1：

> 默认配置：`{"theme": "light", "window": {"width": 800, "height": 600}}`
>
> 用户配置：`{"theme": "dark", "window": {"width": 1024}}`
>
> 输出：{"theme": "dark", "window": {"width": 1024, "height": 600}}

#### 示例 2：

> 默认配置：`{"a": 1}`
>
> 用户配置：`{"b": 2}`
>
> 输出：{"a": 1, "b": 2}

#### 提示：

- 文件编码为 UTF-8
- 使用 `json.load()` 读取文件
- 不要修改原字典，可以构造新字典
