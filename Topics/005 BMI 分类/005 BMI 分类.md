## 005 BMI 分类

给定体重 `weight`（千克）和身高 `height`（米），计算 `BMI = weight / height²`，并按下列规则返回分类：

- 小于 `18.5`：`"偏瘦"`
- 小于 `24`：`"正常"`
- 小于 `28`：`"偏胖"`
- 其余：`"肥胖"`

#### 示例 1：

> 输入：weight = 60, height = 1.75
>
> 输出："正常"

#### 示例 2：

> 输入：weight = 90, height = 1.70
>
> 输出："肥胖"

#### 提示：

- `0 < weight <= 500`
- `0 < height <= 3`
- 注意分支判断的先后顺序
