## 048 集合关系报告

给定两个整数列表 `a` 和 `b`，把它们视为集合，返回二者的交集、并集、`a` 对 `b` 的差集和对称差集。

所有结果都以升序列表表示，返回格式为 `{"intersection": ..., "union": ..., "difference": ..., "symmetric_difference": ...}`。

#### 示例 1：

> 输入：a = [1, 2, 2, 3], b = [2, 3, 4]
>
> 输出：{"intersection": [2, 3], "union": [1, 2, 3, 4], "difference": [1], "symmetric_difference": [1, 4]}

#### 示例 2：

> 输入：a = [], b = [1]
>
> 输出：{"intersection": [], "union": [1], "difference": [], "symmetric_difference": [1]}

#### 提示：

- `0 <= len(a), len(b) <= 10^5`
- 注意差集具有方向性
