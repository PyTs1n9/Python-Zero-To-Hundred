## 059 牛顿法求平方根

给定非负数 `x` 和精度 `epsilon`，用牛顿迭代法求 `x` 的平方根。

迭代公式为 `next = (current + x / current) / 2`。当前后两次结果之差小于 `epsilon` 时停止，返回最终结果。

#### 示例 1：

> 输入：x = 2, epsilon = 0.000001
>
> 输出：约 1.414214

#### 示例 2：

> 输入：x = 0, epsilon = 0.001
>
> 输出：0.0

#### 提示：

- `0 <= x <= 10^12`
- `0 < epsilon < 1`
- `x = 0` 需要单独处理
