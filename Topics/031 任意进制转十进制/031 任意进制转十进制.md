## 031 任意进制转十进制

给定字符串 `num` 和进制 `base`，将 `num` 转换成十进制整数。

数字字符使用 `0~9`，字母使用 `A~F`，输入不区分字母大小写。

#### 示例 1：

> 输入：num = "101101", base = 2
>
> 输出：45

#### 示例 2：

> 输入：num = "ff", base = 16
>
> 输出：255

#### 提示：

- `2 <= base <= 16`
- `1 <= len(num) <= 30`
- `num` 中的每一位都保证在给定进制下合法
- 本题要求逐位计算，不直接调用 `int(num, base)`
