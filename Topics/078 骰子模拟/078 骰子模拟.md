## 078 骰子模拟

给定试验次数 `n` 和随机种子 `seed`，创建独立随机数生成器，模拟掷两个六面骰子 `n` 次。

返回点数之和 `2~12` 各自出现次数的字典，所有键都必须存在。

#### 示例 1：

> 输入：n = 3, seed = 0
>
> 三次随机结果对应的点数和：8、4、9
>
> 输出：{2: 0, 3: 0, 4: 1, 5: 0, 6: 0, 7: 0, 8: 1, 9: 1, 10: 0, 11: 0, 12: 0}

#### 示例 2：

> 输入：n = 0, seed = 10
>
> 输出：所有次数均为 0 的字典

#### 提示：

- `0 <= n <= 10^6`
- 使用 `rng = random.Random(seed)`，避免影响全局随机状态
- 每个骰子使用 `rng.randint(1, 6)`
