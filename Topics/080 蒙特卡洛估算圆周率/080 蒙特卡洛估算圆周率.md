## 080 蒙特卡洛估算圆周率

在正方形 `[0, 1] × [0, 1]` 内随机生成 `n` 个点。落在四分之一单位圆内的比例约为 `π / 4`。

给定 `n` 和随机种子 `seed`，使用独立随机数生成器估算圆周率，结果四舍五入到六位小数。

#### 示例 1：

> 输入：n = 100000, seed = 0
>
> 输出：一个接近 3.141593 的浮点数

#### 示例 2：

> 输入：n = 0, seed = 0
>
> 输出：0.0

#### 提示：

- `0 <= n <= 10^7`
- 对随机点 `(x, y)`，若 `x² + y² <= 1` 则位于圆内
- 使用 `random.Random(seed).random()`
