## 023 字符分类统计

给定字符串 `s`，统计其中英文字母、数字、空白字符和其他字符的数量。

以字典 `{"letter": 字母数, "digit": 数字数, "space": 空白数, "other": 其他数}` 的形式返回。

#### 示例 1：

> 输入：s = "Py 3.10!"
>
> 输出：{"letter": 2, "digit": 3, "space": 1, "other": 2}

#### 示例 2：

> 输入：s = "你好\n2026"
>
> 输出：{"letter": 2, "digit": 4, "space": 1, "other": 0}

#### 提示：

- `0 <= len(s) <= 10^5`
- Python 的字符判断方法也能识别 Unicode 字母和数字
