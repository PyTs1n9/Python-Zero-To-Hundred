# Python 二级编程训练题库

本项目包含 **100 道 Python 编程题**，题号从 `001` 到 `100`，面向已经掌握 Python 基础语法，但对全国计算机等级考试二级 Python 的常用库、文件操作和综合应用题还不熟悉的学习者。

题目采用类似 LeetCode 的描述方式，每题包含题目要求、输入输出示例和提示。题库不追求偏难、偏怪的算法，而是训练二级考试最需要的能力：**读懂要求、拆分步骤、正确编码、处理边界、按格式输出**。

> 考试范围和考试环境可能随批次调整，备考时请同时核对当次官方考试大纲与机考环境。

## 项目结构

每道题使用独立文件夹，题目文件与文件夹同名：

```text
Python Zero To Win/
├─ 001 温度转换/
│  └─ 001 温度转换.md
├─ 002 圆的面积和周长/
│  └─ 002 圆的面积和周长.md
├─ ...
└─ 100 校园消费综合分析/
   └─ 100 校园消费综合分析.md
```

建议把自己的代码保存在对应题目文件夹中，例如：

```text
001 温度转换/
├─ 001 温度转换.md
└─ solution.py
```

### 第一阶段：基础操作题能力（001–035）

这一阶段解决“能不能快速写对”的问题。重点不是复杂算法，而是熟练掌握：

- 运算符、分支、循环和格式化输出；
- 字符串的索引、切片、遍历和常用方法；
- 空值、负数、重复值、边界值等特殊情况；
- 把自然语言规则准确翻译成判断条件。

完成标准：大部分题能在 **10–15 分钟**内独立写完，并一次通过示例。

### 第二阶段：简单应用题能力（036–060）

这一阶段训练“如何选择合适的数据结构并组织代码”。重点掌握：

- 列表负责有序数据，字典负责映射和计数，集合负责去重和关系运算；
- 使用 `sorted()`、多关键字排序和稳定排序；
- 把重复逻辑提取成函数；
- 正确处理递归终止条件、下标变化和二维列表。

完成标准：看到“统计、去重、分组、排名、合并”等关键词时，能迅速判断应该使用哪种数据结构。

### 第三阶段：文件与常用库（061–093）

这是二级操作题最容易拉开差距的部分，应重点反复练习。

文件处理必须形成固定习惯：

```python
with open(path, "r", encoding="utf-8") as file:
    data = file.read()
```

训练时重点掌握以下内容：

- 文件路径、打开模式、编码、换行符和上下文管理器；
- CSV 的表头与字段转换，JSON 的读取与写出；
- 使用异常处理跳过非法数据，而不是让整个程序退出；
- `math` 的常用数学函数；
- `random` 的随机数、随机选择、随机抽样和随机种子；
- `time` 的时间解析与格式化；
- `turtle` 的移动、转向、抬笔落笔、填充和坐标定位；
- `jieba` 的精确分词、词频统计和停用词过滤；
- PyInstaller 常用打包参数的含义。

完成标准：不查资料也能写出文件读写、词频统计、CSV 汇总、基础 turtle 图形和 jieba 分词的代码框架。

### 第四阶段：综合应用题（094–100）

综合题通常不是某个知识点特别难，而是步骤多、格式严、容易遗漏。推荐按下面的固定顺序完成：

1. 先写出输入数据的结构和最终输出结构；
2. 读取数据，但暂时不做统计；
3. 逐条校验并清洗数据；
4. 使用字典或列表完成累计、分组和排序；
5. 最后统一处理小数位、名次和文件输出；
6. 用空文件、错误行、并列数据和单条数据复测。

不要一开始就把所有逻辑写在一个大循环里。把“校验一行”“计算等级”“生成排名”等独立步骤写成函数，出错时更容易定位。

## 推荐刷题方法

每道题至少完成以下四步：

1. **复述题意**：明确输入、输出、排序规则、保留位数和异常情况；
2. **独立编码**：先不看提示，卡住 10 分钟后再看提示；
3. **主动测试**：除了题目示例，自己补充至少 3 个边界用例；
4. **记录错误**：标记错误属于语法、思路、库函数、格式还是边界遗漏。

建议测试的常见边界：

- 空字符串、空列表、空文件；
- `0`、`1`、负数和最大值；
- 全部相同、全部不同、重复值；
- 查找不到、只有一个结果、多个结果并列；
- 文件最后一行没有换行符；
- CSV 字段缺失、数字转换失败、日期非法；
- 小数四舍五入和输出格式；
- 排序主关键字相同时的次关键字。

## 四周备考方案

### 第 1 周：打牢语法

- 完成 `001–035`；
- 每天约 5–7 题；
- 重点检查分支边界、循环次数、字符串方法和格式化输出。

### 第 2 周：组合数据与函数

- 完成 `036–060`；
- 每天约 4–5 题；
- 每道统计题至少分别思考列表、字典和集合三种方案，再选择最合适的一种。

### 第 3 周：文件和库专项

- 完成 `061–093`；
- 文件、CSV、JSON、异常、`random`、`time`、`turtle`、`jieba` 分块练习；
- 把常用库的高频函数整理成一页自己的速查表。

### 第 4 周：综合题和限时训练

- 完成 `094–100`；
- 重做之前标记为错误或超时的题；
- 至少进行两次完整限时模拟；
- 模拟时关闭搜索和代码补全，尽量接近真实机考环境。

## 二级应试重点

二级 Python 机考通常同时包含选择题和操作题。常见计分结构中，选择题约占 `40` 分，操作题约占 `60` 分；操作题又可分为基础操作、简单应用和综合应用。具体题型与分值应以当次官方要求为准。

备考时不要只刷代码。部分考试规则不仅要求总分合格，还会对选择题得分设置最低要求，因此选择题中的公共基础知识、Python 语法和程序阅读也必须复习。

### 考场时间建议

按常见的 120 分钟考试安排，可参考：

| 环节 | 建议时间 |
| --- | ---: |
| 选择题 | 30 分钟 |
| 基础操作题 | 20 分钟 |
| 简单应用题 | 25 分钟 |
| 综合应用题 | 35 分钟 |
| 检查与保存 | 10 分钟 |

如果某道题连续卡住，应先保存已有代码并继续下一题。先拿到确定的分数，再回头攻克难点。

### 操作题高频失分点

- 修改了题目不允许修改的代码；
- 函数名、参数、返回值或输出文件名不符合要求；
- 多输出了提示语、调试信息或空格；
- 忘记把 `input()` 得到的字符串转换成数字；
- 排序方向错误，或遗漏并列情况下的第二排序条件；
- 文件模式使用错误，导致原文件被覆盖；
- 忘记指定 UTF-8 编码或关闭文件；
- 只处理正常数据，没有处理空数据和非法数据；
- turtle 图形的角度、循环次数或抬笔落笔位置错误；
- 代码只对样例有效，换一组数据就失败；
- 写完代码没有真正运行，也没有检查输出文件。

### 考场检查清单

提交前逐项确认：

- [ ] 代码可以从头到尾运行，没有语法错误；
- [ ] 题目指定的文件名、函数名和变量名没有改错；
- [ ] 没有遗留 `print()` 调试信息；
- [ ] 输出类型、顺序、大小写和小数位正确；
- [ ] 文件已经写入指定位置，内容不是空的；
- [ ] 空输入、单个元素和并列情况已经考虑；
- [ ] 所有修改已经保存。

## 达标参考

达到下面的状态后，再参加考试会更稳妥：

- `001–050` 正确率达到 `90%` 以上；
- `051–083` 正确率达到 `80%` 以上；
- 能从空白文件写出常用的文件、CSV、JSON、turtle 和 jieba 代码框架；
- `094–100` 每题能在 `35–45` 分钟内独立完成；
- 两次限时模拟中，操作题都能稳定拿到 `48/60` 以上；
- 错题重做时不再依赖原代码。

真正有效的备考不是“看懂了”，而是能够在规定时间内，独立写出、运行通过并检查无误。建议严格按照题号推进，同时保留错题记录，直到同类问题不再重复出错。
