# Python Zero To Win

一个用于练习 Python 编程与数据清洗的学习项目。

## 项目目录

```text
Python-Zero-To-Win/
├─ Topics/             # Python 编程练习题
│  ├─ 001 ... 100/     # 题目说明
│  └─ Answer/          # 参考答案与配套数据
├─ DataClean/          # 数据清洗练习
│  └─ xxx Test/
│     ├─ topic.md      # 题目说明
│     ├─ content/      # 练习数据
│     └─ answer/       # 参考代码与输出结果
└─ README.md           # 项目说明
```

- `Topics`：包含基础语法、数据结构、文件操作、常用库和综合应用等练习。
- `DataClean`：包含缺失值、重复值、异常数据、数据脱敏等数据清洗案例。
